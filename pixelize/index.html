Pixelize

A tool that pixelizes art: it turns Photoshop files (.psd / .psb) and regular images into pixel-art sprites, then lets you fix them pixel by pixel. It started as a Cocos Creator extension, and there is a Unity version too. Both run the same portable C core, here compiled to WebAssembly, so everything stays in your browser.
